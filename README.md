# Nightmare Core 💀

## ¿What is the Nightmare Core plugin 💀?

It is an add-on that tries to turn the normal experience of a Minecraft user into a nightmare with great difficulty in advancing in the game.

### Minecraft Requirements

The Nightmare Core plugin requires the following environment to function correctly:

#### Core Requirements

- Minecraft Version: 1.21.1
- Java Version: Java 21 or higher

### Dependencies

- PlaceholderAPI: Required for handling dynamic data and custom display variables.
